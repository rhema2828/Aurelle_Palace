# Aurelle Palace — Luxury Island Resort Website

**Tagline:** Where the Ocean Meets Elegance

## 1. Project idea
Aurelle Palace is a fictional luxury island-resort concept website inspired by the calm, immersive atmosphere of tropical beach destinations. It introduces visitors to the resort, villas, island experiences, dining, wellness, and contact options through a polished, editorial-style interface.

### Purpose
- Present the resort concept and its experiences in an attractive, easy-to-navigate way.
- Let visitors explore villa details, browse dining and wellness information, and send demo enquiries.
- Demonstrate core front-end web design and interaction skills without requiring a backend.

### Target audience
Travellers interested in luxury island holidays, couples planning a getaway, families comparing accommodation, and visitors exploring resort dining or wellness experiences.

## 2. Features
- Responsive layout for desktop, tablet, and mobile screens.
- Ocean-inspired hero area and resort imagery.
- Navigation to villas, experiences, dining, wellness, and contact.
- Interactive navigation/menu controls and section links.
- Dedicated villa detail pages with image galleries, room features, and booking enquiry links.
- Dining and wellness content sections.
- Contact form with front-end demo confirmation.
- Booking enquiry interaction for demonstration purposes.
- Refined typography using Cormorant Garamond and Manrope.

## 3. Technology stack
- **HTML5** — page structure and content
- **CSS3** — responsive layout, styling, and animation
- **Vanilla JavaScript** — menu controls, page interactions, and demo form responses
- **Google Fonts** — typography
- **Unsplash image URLs** — supporting resort photography

No backend, authentication, or database is used, in accordance with the front-end-only assignment requirements.

## 4. Project files
- `index.html` — homepage and main resort experience
- `room-details.html` — villa detail page; accepts `?room=beach` or `?room=ocean`
- `contact.html` — contact and enquiry page
- `style.css` — shared styles and responsive rules
- `script.js` — front-end interactions
- `assets/` — local hero and resort background assets

## 5. Run locally
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` with the **Live Server** extension, or use any static HTTP server.
4. An internet connection is recommended for Google Fonts and remote Unsplash images.

You can also open `index.html` directly in a browser, although a local server is recommended for development.

## 6. Deploy with GitHub Pages
1. Create a new **public** repository on GitHub, for example `aurelle-palace`.
2. Upload the contents of this folder to the repository root. Make sure `index.html` is at the root, not inside another nested project folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/(root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish. The live URL will usually look like `https://YOUR-USERNAME.github.io/aurelle-palace/`.
7. Copy both the repository URL and the live Pages URL for submission. The live URL appears in **Settings → Pages** after deployment.

## 7. Demo limitations
Aurelle Palace is a student concept website, not a real resort. Booking and contact interactions only show front-end demo feedback; they do not submit to a server or create real reservations. Contact details are placeholders. Images and web fonts loaded from external providers require internet access.
